  CHETTINAD TILES  –  Athangudi Tiles Board Game
  Online Multiplayer Edition  |  v1.0
═══════════════════════════════════════════════════════════════

▶  HOW TO PLAY
──────────────
1. Double-click ChettinadTiles.exe to launch the game.
2. Enter your player name.
3. Click "Create Lobby" to start a new game room.
   – You'll receive a 6-character Lobby Code.
   – Share this code with up to 5 friends worldwide.
4. Friends enter your code and click "Join Lobby".
5. Once 2–6 players have joined, the Host clicks "START GAME".

▶  GAME RULES  (4 Rounds)
───────────────────────────
Each round:
  1. Pick 4 tiles from the Supply.
  2. Pass tiles: 3 left → receive 3 right; 2 left → receive 2; 1 left → receive 1.
  3. Place 1–4 tiles on your 4×4 Floor. Rest go to Storage.
  4. Lose 1 Storage slot (start with 4, end Round 4 with 0).
  5. Scoring!

▶  SCORING
───────────
After EACH Round:
  a) +1 per completed motif  (2×2 block of matching corner motifs)
  b) +1 per 3 centrepieces in a row/col/diagonal  (same centrepiece type)
  c) +2 per 4 centrepieces in a row/col/diagonal
  d) +2 per completed Goal  (match 3 motifs in a goal-shape)

End of Game only:
  e) +1 per half-motif on the 4 edges of your Floor

Highest total score wins!

▶  TILES
──────────
Each tile has:
  • 1 centrepiece (Star, Flower, Butterfly, Diamond, Pinwheel)
  • 4 corner motifs (Leaf, Petal, Arrow, Swirl)

▶  GOALS
──────────
3 Goals are set at game start (columns of 3 motif types).
Complete a goal by matching those 3 motifs in:
  – A row, column, or diagonal
  – An L-shape
  – Wrapped around the edges of the floor
Goals can be completed multiple times (without shared tiles per completion).

▶  CONTROLS
────────────
  • Click a tile in your Hand → click an empty floor cell to place it.
  • Click "→ Store" to send a tile to Storage instead.
  • Right-click or press ESC to deselect a tile.
  • Click "Done Placing" when finished.

▶  LOCAL / ONLINE
──────────────────
  Online:  Default server  wss://chettinad-tiles.onrender.com
           (Free tier – may take 30s to wake up on first connection)

  Local:   Click "Play Locally" on the title screen to host a local game.
           Others on the same network can connect via  ws://YOUR-IP:8765

▶  SELF-HOSTING
────────────────
  Run  run_server.bat  to start your own server.
  Others connect using  ws://YOUR-PUBLIC-IP:8765
